# PrusaXL_TweakedGCode
A set of well-tested G-Code tweaks to allow for optimal operation

This repo contains what I believe are saner, more reasonable starting GCode options for the Prusa XL printer. Where possible, I have made comments to show why I made certain changes. These changes include lowered temps for bed probing, an option for extended pre-heat, and better use of idle temp settings.
